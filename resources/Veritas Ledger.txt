# Veritas Ledger 

> **Smart India Hackathon 2026** | **Problem Statement ID:** 26190  
> **Domain:** Ministry of Home Affairs (MHA) / Police, Judicial & Forensic Infrastructure  
> **Title:** Secure Digital Document Management System for Legal & Investigation Documents

Veritas Ledger is a tamper-proof digital evidence management system bridging police stations (CCTNS), forensic laboratories (e-Forensics), and criminal courts (e-Courts). The system provides automated Indic document understanding, local AES-256-GCM encrypted object storage, PII anonymization, statutory Bharatiya Nyaya Sanhita (BNS) compliance checking, and zero-gas cryptographic custody anchoring on an EVM ledger compliant with **Section 63 of the Bharatiya Sakshya Adhiniyam (BSA), 2023**.

---

## 🏛️ System Architecture

```text
Field Capture / Ingestion (PDF / Scanned Images)
           │
           ▼
[FastAPI AI Service :8000] ──► Pytesseract OCR (English + Hindi)
           │                ──► Microsoft Presidio (PII Anonymization)
           │                ──► BNS / BNSS Statutory Rule Engine
           ▼
[Node.js Relayer :5000]     ──► Local AES-256-GCM Encryption
           │
     ┌─────┴────────────────────────────────┐
     ▼                                      ▼
[MinIO Storage :9000]             [Sepolia Smart Contract]
Payload: IV + Tag + Ciphertext     Notarized: SHA-256 Digest
Key: cases/:caseId/:file.enc       Parent-Child Custody Hash Linkage
                                   Admissibility Metadata (BSA Sec. 63)

```

🛠️ Tech Stack
--------------

*   **Frontend:** React 18, Vite, Tailwind CSS, Lucide Icons
    
*   **API Backend:** Node.js (Express), @aws-sdk/client-s3, ethers.js v6, Multer
    
*   **AI & Document Intelligence:** Python 3.11+, FastAPI, Uvicorn, Pytesseract, Microsoft Presidio, SpaCy (en\_core\_web\_sm), PyPDF
    
*   **Off-Chain Object Store:** MinIO (S3-compatible, containerized rootless via Podman)
    
*   **Trust Anchor:** Solidity (EvidenceRegistry.sol), Hardhat, Sepolia Testnet
